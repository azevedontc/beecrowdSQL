## 📌 Sobre

Este repositório reúne minhas resoluções para os exercícios de **SQL** da plataforma [beecrowd](https://www.beecrowd.com.br) (ex-URI Online Judge), todas testadas e aprovadas (**Accepted**) usando **PostgreSQL**.

O objetivo é praticar consultas relacionais do dia a dia de um analista/engenheiro de dados: filtros, agregações, `JOIN`s, subqueries, funções de janela e formatação de saída — e também servir de referência rápida para quem está estudando SQL e travou em algum problema parecido.

<br>

## 🗂️ Estrutura

```
beecrowdSQL/
├── answers/          # uma query .sql por problema, nomeada com o número do exercício
│   ├── 2602.sql
│   ├── 2603.sql
│   └── ...
├── README.md
└── LICENSE.md
```

Cada arquivo em `answers/` contém **apenas a query** submetida e aceita no judge — sem comentários extras — para servir de gabarito direto e fácil de comparar com sua própria tentativa.

<br>

## 🚀 Como usar

1. Encontre o número do exercício que você está travado (aparece na URL do problema no beecrowd).
2. Procure o arquivo correspondente em `answers/<numero>.sql`.
3. Compare a lógica com a sua tentativa — evite copiar e colar direto, o aprendizado vem de entender o "porquê".

<br>

Encontrou um exercício com solução mais elegante, mais performática, ou quer sugerir um problema ainda não resolvido? Abra uma *issue* ou um *pull request* — toda contribuição é bem-vinda.
